# mediawiki2markdown

Dump MediaWiki pages into Markdown files.

The converter asks MediaWiki to render each page before passing its HTML to Pandoc. This preserves content generated by templates, parser functions, and extension tags such as `<tabs>`.

## Usage

```bash
python mediawiki2markdown.py \
  --site wiki.example.org \
  --path /mediawiki/ \
  --output-dir wiki_markdown_dump
```

Run `python mediawiki2markdown.py --help` for all options.
